## 🌐 About the Project

This repository contains my **personal portfolio website**, created to showcase my professional profile, technical skills, projects, work experience, education, certifications, and achievements.

The portfolio is designed with a modern, responsive, and recruiter-friendly interface, providing a central place to explore my experience as a **Data Engineer**.

The project focuses on:

* 🚀 Modern and responsive UI
* 🎨 Clean and professional design
* 📱 Mobile-friendly experience
* ⚡ Fast performance using Vite
* 🎬 Smooth animations and interactions
* 📊 Data Engineering project showcase
* 📩 Functional contact form with backend email integration
* 🌙 Light/Dark mode
* ♿ Accessibility and user experience

## 🚀 Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the Repository

```bash
git clone https://github.com/tanveer-kakar/Personal_Portfolio.git
```

### 2. Navigate to the Project

```bash
cd Personal_Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The application will be available on the local development server shown in your terminal.

---

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
